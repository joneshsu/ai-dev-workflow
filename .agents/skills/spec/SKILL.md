你要協助我為以下功能撰寫需求規格：

（使用者呼叫此 skill 時附上的功能描述）

步驟：
1. 先閱讀 `AGENTS.md`、`docs/project/`（若存在，特別是 roadmap 中對應的功能）與相關程式碼，理解現況。
2. **先向我提出 3～5 個釐清問題**（範圍、邊界情況、非目標），等我回答後再繼續。
3. 依照 `docs/specs/_template.md` 撰寫規格，檔名為 `docs/specs/NNN-<kebab-case-標題>.md`（NNN 為下一個流水號）。
4. 驗收標準必須具體、可測試（Given / When / Then）。
5. 不要寫任何程式碼。完成後列出檔案路徑，並提醒我下一步執行 plan skill。
