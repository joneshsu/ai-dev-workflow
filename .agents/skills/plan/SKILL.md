請依據使用者指定的規格檔（位於 `docs/specs/`）產生實作計畫。若使用者沒有指定，列出 `docs/specs/` 中尚未有對應 plan 的規格讓使用者選擇。

步驟：
1. 閱讀規格與相關程式碼。**不要修改任何程式碼。**
2. 依照 `docs/plans/_template.md` 撰寫計畫，檔名與 spec 相同編號，放在 `docs/plans/`。
3. 把工作拆成小步驟，每一步都要：可以獨立 commit、有對應的測試、說明會改動哪些檔案。
4. 在「假設與待確認事項」列出你不確定的地方。
5. 若有需要記錄的技術決策（選型、架構取捨），列在「需要 ADR 的決策」。
6. 完成後停下來，請我審查計畫。我確認後再執行 implement skill。
